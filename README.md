# OpenBrush

A cross-platform paint program modelled on the modern Windows 11 Paint.
Runs natively on Windows, Linux and macOS.

Written entirely in Rust, using [egui](https://github.com/emilk/egui) for the interface
and [tiny-skia](https://github.com/linebender/tiny-skia) for rendering.
